## 能做什么

- 全屋同步播放
- 分区独立播放
- 无线 5.1 环绕声（规划中）
- 手机音源接入（AirPlay / 蓝牙 / DLNA / Spotify Connect）
- 智能家居集成（Home Assistant / Music Assistant / ESPHome）
