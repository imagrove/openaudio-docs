# 分区独立播放

不同房间/喇叭播放**完全不同**的内容（多区），与"多声道"不同：多区彼此独立、**无需同步**。

## 原理

Snapserver 提供多个独立的音频流（Stream），每个 ESP32 节点订阅其中一个。

- 同一流内的多个节点：严格同步
- 不同流之间：完全独立

## 配置

1. 服务端：为每个区域定义一个 stream（见 [Snapserver 安装](../server/snapserver.md)）
2. 音源：每个区域跑一个播放器实例，写入对应 pipe
3. 节点：配置订阅对应的 `stream_id`（或通过 JSON-RPC 动态切换）

## 资源

- 每个独立流多占一份解码 CPU
- 未压缩 PCM 约 1.4 Mbps/流；可启用 FLAC 压缩降至约一半
